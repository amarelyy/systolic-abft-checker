Part 4: datapath faults at the value level (W = 18, 20000 pairs per fault position)
  A fault is modelled by the values it corrupts, not cycle by cycle.
  'a-token': one activation A[i][k] is wrong from column c0 onwards (affects row i).
  'a-stuck': a stuck bit in the register that passes activations along row k, so every
             activation of column k is forced from column c0 onwards (affects many rows).
  'w-stuck': a stuck bit in a stored weight B[k][j] (affects column j).

  a-stuck                192 x 1   3383711   3383711        0
  w-stuck                256 x 1   2500800   2500800        0
